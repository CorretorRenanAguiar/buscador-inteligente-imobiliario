# buscador-inteligente-imobiliario
Plataforma web inteligente para recomendação e segmentação de leads imobiliários utilizando Inteligência Artificial (IA), Machine Learning (ML), chatbot automatizado e análise de dados. Projeto acadêmico desenvolvido no IF Sudeste MG com foco em inovação, automação e mercado imobiliário digital.
